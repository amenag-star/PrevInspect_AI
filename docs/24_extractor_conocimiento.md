\# Extractor Inteligente de Conocimiento

\## PrevInspect AI



\## Objetivo



Transformar documentos en conocimiento estructurado para alimentar el Sistema Experto.



No solo extrae texto: clasifica, relaciona, propone reglas y actualiza la base de conocimiento.

Cada documento procesado deberá transformarse en conocimiento reutilizable por PrevInspect AI.



Nunca deberá quedar únicamente como texto almacenado.
